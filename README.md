# ব্লাড সেবা (Blood Seva) - ফায়ারবেস ক্লাউড চালিত ব্লাড ডোনার প্ল্যাটফর্ম

একটি আধুনিক, মোবাইল-রেসপন্সিভ রক্তদান প্ল্যাটফর্ম। এই ভার্সনে **Google Firebase (Firestore Cloud Database)** যুক্ত করা হয়েছে, যার ফলে ডেটা শুধু ব্রাউজারের লোকাল স্টোরেজে থাকবে না—সরাসরি ক্লাউডে রিয়েলটাইমে সংরক্ষিত ও সিঙ্ক থাকবে।

---

## 🚀 কীভাবে চালাবেন (How to Run)

আপনার প্রোজেক্টে দুটি সহজ উপায়ে চালাতে পারেন:

### উপায় ১: সরাসরি ব্রাউজারে ওপেন করে (সবচেয়ে সহজ)
কোনো কমান্ড রান করা ছাড়াই সরাসরি [index.html](file:///d:/Blood/blood/index.html) ফাইলটি যেকোনো ব্রাউজারে (Chrome বা Edge) ওপেন করুন।

### উপায় ২: `npm` ও Vite Dev Server দিয়ে
টার্মিনালে প্রজেক্ট ফোল্ডারে গিয়ে রান করুন:
```bash
npm install
npm run dev
```

## 🔥 ফায়ারবেস (Firebase) কানেক্ট করার নিয়ম (মাত্র ২ মিনিট)

লোকাল স্টোরেজের বদলে ক্লাউডে ডেটা রাখার জন্য ফায়ারবেসে মাত্র কয়েকটি ধাপ সম্পন্ন করুন:

### ধাপ ১: প্রজেক্ট তৈরি করুন
1. [Firebase Console](https://console.firebase.google.com/) এ যান এবং আপনার গুগল একাউন্টে লগইন করুন।
2. **"Add project"** বাটন চাপুন এবং প্রজেক্টের নাম দিন (যেমন: `blood-donor-bd`)।

### ধাপ ২: ক্লাউড ডাটাবেস (Firestore) চালু করুন
1. প্রজেক্ট তৈরির পর বাম পাশের মেনু থেকে **Build > Firestore Database**-এ যান।
2. **"Create Database"** চাপুন।
3. Security Rules হিসেবে **"Start in test mode"** নির্বাচন করুন (যাতে সবার জন্য পড়া ও লেখার অনুমতি থাকে)।

### ধাপ ৩: কীগুলো (Keys) সাইটে বসান
1. প্রজেক্টের হোমপেজ থেকে **Web App** ( `</>` আইকন) সিলেক্ট করে অ্যাপ রেজিস্টার করুন।
2. সেখানে প্রদর্শিত `firebaseConfig` থেকে তথ্যগুলো:
   * সরাসরি সাইটের উপরে থাকা **"ফায়ারবেস সেটিংস"** বাটনে চাপ দিয়ে বসিয়ে সেভ করতে পারেন।
   * অথবা [firebase-config.js](file:///d:/Blood/blood/firebase-config.js) ফাইলটি ওপেন করে `defaultFirebaseConfig` অবজেক্টে পেস্ট করে দিতে পারেন:

```javascript
export const defaultFirebaseConfig = {
  apiKey: "আপনার_API_KEY",
  authDomain: "আপনার_PROJECT_ID.firebaseapp.com",
  projectId: "আপনার_PROJECT_ID",
  storageBucket: "আপনার_PROJECT_ID.appspot.com",
  messagingSenderId: "আপনার_SENDER_ID",
  appId: "আপনার_APP_ID"
};
```

ব্যাস! সাথে সাথে সাইটের উপরে সবুজ চিহ্ন আসবে:
`✅ ফায়ারবেস ক্লাউড কানেক্টেড (রিয়েলটাইম সিঙ্ক সক্রিয়)`

## 🌟 প্ল্যাটফর্মের মূল ফিচারসমূহ

1. **সাধারণ গ্রহীতা (No Login):**
   * লগইন ছাড়াই রক্তের গ্রুপ ও জেলা অনুযায়ী রক্তদাতা খুঁজে পাবেন।
   * প্রস্তুত ডোনারদের সরাসরি এক ক্লিকে কল (`tel:01XXXXXXXXX`) করতে পারবেন।

2. **৯০ দিনের অটো-লক ও কাউন্টডাউন:**
   * রক্তদাতা রক্তদানের পর ড্যাশবোর্ডে **"আমি রক্ত দিয়েছি"** বাটনে চাপ দিবেন।
   * ফায়ারবেস ক্লাউডে তাৎক্ষণিক **৯০ দিনের কাউন্টডাউন** শুরু হয়ে যাবে।
   * আগামী ৯০ দিন এই রক্তদাতার ফোন নম্বর ও কল বাটন স্বয়ংক্রিয়ভাবে লক থাকবে।

3. **এডমিন প্যানেল ও রিভিউ ব্যবস্থা:**
   * **ম্যানুয়াল ডোনার যোগ:** এডমিন নিজে সরাসরি ডোনার যোগ করতে পারেন।
   * **পেন্ডিং রিভিউ:** কোনো রক্তদাতা একাউন্ট খুললে তা প্রথমে এডমিন প্যানেলে পেন্ডিং থাকে। এডমিন অনুমোদন (Approve) করলেই তা ফায়ারবেসে একটিভ হয়ে সাধারণ তালিকায় দৃশ্যমান হয়।
   * **এডমিন লগইন তথ্য:**
     * ইউজারনেম: `admin`
     * পাসওয়ার্ড: `admin123`
